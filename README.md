# Palestine.github.io — Historical Research Repository

A source-linked public history project exploring Palestine, its people, names, geography, culture, political history, and contemporary status. The site is designed for GitHub Pages and uses standalone HTML/CSS/JavaScript with Markdown research chapters and JSON records.

## Project status

**Research foundation / actively expandable.** The bilingual landing page and initial research framework are populated. The chapter files are concise, evidence-conscious starting syntheses, not a claim that every subject has been exhaustively researched. Dates, links, and interpretations should be reviewed as the archive grows.

## Preview locally

Open `index.html` in a browser. The page is self-contained and does not require a build step or external JavaScript libraries. Markdown chapter links are best viewed on GitHub or in a Markdown viewer.

## Publish with GitHub Pages

1. Upload the contents of this project folder to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Choose deployment from the `main` branch and the `/ (root)` folder.
4. Save, then wait for the Pages deployment workflow to finish.
5. Check the Pages URL and confirm that `index.html` loads.

The research foundation and bilingual `index.html` are committed to `main`. GitHub Pages publication depends on the repository Pages setting.

## Structure

- `index.html` — standalone repository landing page with timeline, source directory, and searchable source register.
- `research/` — chronological and thematic introductory chapters.
- `primary-sources/` — annotated pointers to original documents.
- `methodology/` — source evaluation, disputed claims, and editorial safeguards.
- `data/` — starter timeline, source index, and claim register in JSON.
- `SOURCES.md` — curated source register.
- `CITATION_POLICY.md` — citation standards.
- `CONTRIBUTING.md` — contribution and correction process.
- `updates/changelog.md` — dated project updates.

## Editorial commitments

1. Distinguish primary evidence from later interpretation.
2. Cite sources close to the claim they support.
3. Preserve historical terminology while explaining its context.
4. Distinguish geography, population, identity, political authority, and state sovereignty.
5. Treat institutional sources as authoritative evidence of what an institution stated or decided—not as automatically exhaustive or beyond scrutiny.
6. Include credible counter-evidence and document disputes.
7. Date all current-affairs data and update it when it changes.
8. Maintain a visible correction log.
9. Attribute maps, images, translations, and quotations; respect copyright and licenses.
10. Avoid collective blame, dehumanizing language, and claims that erase the history or humanity of any community.

## Important scope note

The project investigates Palestinian historical continuity, national identity, displacement, rights, and self-determination. It does not presume that an ancient geographical name alone proves uninterrupted modern-style state sovereignty. Nor does a period of foreign rule negate a population's history or rights. Each legal and historical conclusion must be supported by evidence relevant to its time and context.
